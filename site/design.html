Changing a colour

  1. Edit the value in site/palette.css. Light theme on :root, dark on [data-theme="dark"].
  2. Bump the ?v= on the palette.css link in every page so browsers fetch the new file.
  3. Reload this page. Check the swatches, then the contrast tables, then the marks. Nothing else needs touching.
